Tom 猫语音陪聊版

1. 解压 tom-cat-website.zip，保留三个文件在同一目录。
2. 在该目录执行 python3 -m http.server 4173，访问 http://localhost:4173。
   也可以将三个文件部署到 HTTPS 静态网站。不要直接双击 HTML；麦克风需要安全环境。
3. 输入 OpenRouter API Key，测试成功后保存进入。
4. 点击“开始语音陪聊”，允许麦克风，说完一句后稍等。
   Tom 会回答并朗读；开启“回答后继续听我说”可以连续轮流聊天。
5. “打断 Tom”停止朗读并开始听你说；“暂停语音陪聊”关闭麦克风。
   可重听回答、查看字幕、点击猫进行摸摸互动。

当前为二维动画原型，语音识别/朗读使用浏览器 Web Speech API。
浏览器识别服务可能通过网络处理语音，识别结果直接发送到 OpenRouter。
朗读声音由设备提供，不是 Talking Tom 原版声音。
嘴型为朗读开始到结束期间的节奏开合，不是精确的逐音素嘴型。
浏览器必须支持中文语音识别和朗读；功能是否可用还取决于网络、权限和设备语音。
测试和聊天使用 OpenRouter 额度；密钥仅保存在浏览器会话中，显示掩码。
关闭会话后清除密钥；切换到后台会停止语音。

验证：通过语法检查及模拟语音状态测试（门禁、识别结果、朗读、打断、权限错误、清理）。
